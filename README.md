# 커뮤니티 — 첫 구현

## 확정한 제품 방향
- 전 세계에 매일 하나의 공통 질문. 지역별 질문 분리 없이 언어만 번역한다.
- 첫 가입은 로그인과 프로필 등록. 재방문은 질문과 두 선택지로 바로 시작하고, 선택 후 결과 → 댓글 → 배경 이야기 → 양쪽 주장 순서로 읽는다.
- 매일 얻는 보상은 세계의 생각, 생각을 넓히는 도구, 내 선택에 대한 짧은 해석이다.
- 댓글은 무료. 돈은 참여의 입구보다 광고 제거, 심층 기록 분석 같은 추가 가치에서 받는다.
- 핵심 지표는 투표 완료율, 다음 날 재방문, 이유 작성, 반대 의견 열람, 반복 방문이다. 체류시간만으로 성공을 판단하지 않는다.

## 구현된 MVP
- 한국어/영어, UTC 00:00(한국 오전 9시) 날짜 기반 공통 질문.
- 7개 편집 질문 순환, 각 질문별 배경 이야기·생각 도구·양쪽 관점·조건 변경 질문.
- D1에 저장되는 실제 투표와 지역별 집계. 동일 사용자/날짜 중복 투표 금지.
- 선택 이후 댓글 작성·답글·공감·A/B 이유 필터·설득 표시.
- 원래 투표와 별도로 생각 변화 기록.
- 기본 욕설 검사, 분당 댓글 제한, 신고한 글 숨기기, 3명 신고 시 전체에서 숨김.
- 개인 선택 기록, 참여 연속일, 7/30개 선택 진행 표시, 짧은 선택 설명.
- 질문 링크 공유 및 클립보드 대체 흐름.
- ChatGPT 로그인으로 사용자 식별. 투표·댓글·프로필 변경은 서버에서 로그인 여부를 확인한다.
- 데이터 실패 상태와 입력 보존.

## 첫 공개 전 남은 작업
- 이름/도메인 확정 및 질문 원고 30~90개 확장. 7개 반복 질문은 체험용이다.
- 구글·카카오 등 외부 로그인 추가. 현재 ChatGPT 로그인은 지원하며, 과거 비로그인 체험 기록의 계정 병합은 아직 없다.
- 전문 번역/문화 검토. 댓글 번역은 아직 없다.
- 관리자 검토함·이의제기·사용자 차단·더 강한 도배 방지. 현재 신고 집계는 자동 처리이며 운영자 검토를 대체하지 않는다.
- 실제 AI 7/30일 보고서와 근거·불확실성 표시. 현재 해석은 편집된 선택 설명이며 성격 검사나 AI 결과가 아니다.
- 개인정보 고지, 삭제/보유 정책, 운영 약관, 국가별 출시 검토.
- 수익화는 무료 참여 흐름 유지 후 광고/프리미엄을 검증한다. 결제나 광고망은 현재 연결하지 않았다.

## 데이터 정직성
전 세계/국가별 수치는 참여자의 실제 응답이다. 대표 표본의 여론조사가 아니다. 지역은 자기 보고이며 작은 표본은 쉽게 변한다. 편집팀의 예시 관점은 실제 사용자 댓글과 분리했다. 심리 진단, 국민성 판단, 과학적 성격 척도를 주장하지 않는다.

## 코드 구성
`app/world.tsx`: 인터페이스와 한국어/영어 표시.
`lib/questions.ts`: 공통 질문과 일별 선택.
`app/api/world/route.ts`: 서버 검증/집계/저장.
`db/schema.ts`, `drizzle/`: 저장 스키마와 생성된 마이그레이션.

## 검증
TypeScript 검사와 Worker 빌드. 로컬 D1/API로 투표 중복 방지, 지역 집계, 댓글 투표 선행 조건, 답글, 공감 토글, 설득 제약, 신고, 기록 보존, 출처 검사와 입력 길이를 확인한다.

## 커뮤니티 입구 업데이트
- 이름을 커뮤니티(COMMUNITY)로 변경했다.
- 선택한 두 번째 갈림길 이미지를 정지 화면으로 표시한다. 인트로 애니메이션, 3초 대기, 다시 보기/건너뛰기 버튼을 제거하고 로그인 또는 프로필 입력을 즉시 표시한다.
- 로그인 후 닉네임, 성별, 나이대, 나라를 처음 한 번 등록한다. 성별/나이대에는 선택하지 않음 항목이 있다.
- 프로필은 사용자별 D1에 저장하고 다음 방문 때 불러온다. 나이대/성별은 댓글에 노출하지 않는다.
- 첫 장면은 움직이지 않는 경량 WebP 이미지를 사용한다.

## 투표 이후 읽기 순서와 댓글 더보기
- 입장하면 질문/선택 카드만 표시한다. 투표 성공 후 질문 카드를 제거하고 결과 화면으로 전환한다.
- 이미 오늘 투표한 재방문자도 먼저 선택 카드를 보고, `내 선택 결과 보기`를 누르면 기존 투표를 유지한 채 결과를 연다. 프로필에서 다시 입장하면 질문 화면부터 시작한다.
- 화면 순서는 결과 → 댓글 → 배경 이야기 → 양쪽 주장 → 내 선택 해석이다.
- A/B 이유 탭별 최신 댓글을 서버에서 10개씩 불러온다. 추가 댓글은 더보기 요청 시 가져오며, 미리 전체 내용을 내려보내지 않는다.
- 답글은 접힌 상태로 시작하고, 답글도 10개 단위로 추가 로딩한다.
- 현재 모든 댓글 페이지는 무료다. 미래의 결제 여부는 추가 페이지 API의 서버 권한 확인 지점에서 연결할 수 있다. 결제 상품/과금은 아직 구현하지 않았다.

## 회원 계정
- `/signin-with-chatgpt`와 `/signout-with-chatgpt`는 Sites 플랫폼이 처리한다. 자체 비밀번호나 외부 OAuth를 저장하지 않는다.
- `/profile`은 서버에서 로그인을 요구하며, `/api/account`와 모든 참여 쓰기는 플랫폼이 전달한 사용자 ID/이메일로 본인만 식별한다. 클라이언트가 보낸 사용자 ID는 권한에 사용하지 않는다.
- 닉네임 변경은 기존 댓글에도 반영한다. 이메일/성별/나이대는 공개 댓글에 포함하지 않는다.
- 내 댓글은 20개씩 더보기, 선택 기록은 최근 100개를 표시한다. 같은 계정으로 재접속하면 프로필 입력을 건너뛰고 질문부터 보여준다.
- 커뮤니티 탈퇴는 프로필, 투표, 작성자의 반응을 삭제하고 댓글 작성자/본문을 삭제 표시로 익명화한다. 타 회원의 답글과 ChatGPT 계정은 유지한다.
- 비공개 공개 범위는 유지한다. 관리자 화면은 이 변경의 범위에 포함하지 않는다.

## 질문과 결과의 시각 테마
- 입구와 이어지는 차콜 배경, 골드(A)·민트(B) 색상을 질문, 결과, 댓글, 기록, 내 정보에 적용한다.
- 질문은 가운데 정렬하고 날짜별 질문 인덱스에 맞는 정지 WebP 배너를 표시한다. `topic-0.webp`부터 `topic-6.webp`가 7개 질문과 대응한다.
- 투명 배경의 사람 마스코트를 브랜드와 선택 카드, 결과, 댓글 아바타에 사용한다. A/B 글자 배지는 함께 유지한다.
- 배너 한 장은 약 24–45KB이며, 현재 질문에 해당하는 한 장만 요청한다. 입구 애니메이션은 다시 추가하지 않는다.
