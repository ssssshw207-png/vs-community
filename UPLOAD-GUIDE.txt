커뮤니티 원본 코드 — GitHub 업로드 안내

1. ZIP 파일을 다운로드하고 Mac에서 더블클릭해 압축을 풉니다.
2. vs-community 폴더를 엽니다.
3. GitHub Upload files 화면에 폴더 안의 파일과 하위 폴더를 끌어 놓습니다.
4. 업로드가 끝나면 Commit changes를 누릅니다.

ZIP 자체를 GitHub에 올리면 코드가 자동으로 풀리지 않습니다.
GitHub 저장소에 파일을 올리는 것과 웹사이트 배포는 별도 단계입니다.

이 파일은 현재 Sites에서 검증한 커뮤니티 원본입니다.
디자인, 이미지, 질문, 투표, 댓글, 개인 기록 기능의 소스가 포함되어 있습니다.
구글 로그인은 아직 연결되지 않았습니다. 현재 로그인은 Sites의 ChatGPT 인증에 의존합니다.
외부 호스팅에서는 인증 코드, Cloudflare D1 데이터베이스와 빌드 설정을 연결하거나 변경해야 합니다.
GitHub Pages 같은 정적 호스팅만으로 투표·댓글·회원 서버는 실행되지 않습니다.
실제 회원 데이터, 데이터베이스 파일, 비밀 키, node_modules, 빌드 결과는 포함하지 않았습니다.
기존 Site의 project_id는 제거했습니다.
숨김 폴더 .openai의 설정 파일도 원본 빌드에 필요합니다. Mac에서는 Command+Shift+.로 표시할 수 있습니다.

이후 작업: 배포할 호스팅 확정 → 외부 인증 구현 → 데이터베이스 연결 → 구글 앱 설정 → 실제 로그인 검증.
